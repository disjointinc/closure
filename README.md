# RTS

Real-time, schematic entitlements, idempotent metering, billing, pricing versioning, and pricing experimentation.

## Getting started

### Guided (recommended)

RTS is enabled by default for all Disjoint users. Sign up for free at [disjoint.com](https://www.disjoint.com).

### Self-hosted (advanced)

If you want to self-host, you can deploy a hobby instance in one line on Linux using Docker.

```
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/disjointinc/rts/HEAD/bin/deploy-hobby)"
```
